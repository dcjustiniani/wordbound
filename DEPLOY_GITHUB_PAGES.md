# Publish Wordbound with GitHub Pages

Wordbound is a static HTML/CSS/JavaScript game and does not need a server-side backend.

1. Create a GitHub repository for the game.
2. Extract this ZIP on your computer.
3. Upload the **contents** of the `Wordbound_The_Letter_Quest_Polished` folder to the repository root. The root should contain `index.html`, `css/`, `js/`, and `assets/`.
4. Commit the files to the `main` branch.
5. In the repository, open **Settings → Pages**.
6. Under build/deployment, choose **Deploy from a branch**, select `main`, and select `/(root)`. Save.
7. Wait for the Pages deployment to finish, then open the URL shown in the Pages settings.
8. Test the published version, especially tile selection, word submission, sound, and saved progress.

**Important:** Do not upload only the ZIP file or only `index.html`; the game needs its `css`, `js`, and `assets` folders alongside it.
